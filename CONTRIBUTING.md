Contributors are welcome.

Pull Requests:
* Well-formed and documented code and pull requests are required.
* All code shall be thoroughly unit tested. 100% coverage is not required, but it is the goal.
* All code shall be integration tested with other components.
* All contributions, including tests and documentation, shall be 100% human-written. No AI-generated code will be accepted; if there is any suspicion of AI-generated code, your contribution will be rejected, and you will be permanently blacklisted.

Issues:
* Well-formed and documented issues, including the description of the issue and steps to reproduce, are required.

All contributions are equal, but some are more equal than others.
